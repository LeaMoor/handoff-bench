субагенты — его собственные (инструмент Task), Haiku 5.5, всё на подписке Pro. Ячейки 86–93, по 21
эпизоду (шаблоны 1–3 × сиды 1–7), 168 эпизодов, invalid нет. Все прогоны `prefreeze`. Устройство —

## Ячейки

Сбоит только банк: первое списание по фокальному счёту отвечает таймаутом и остаётся невидимым
проверкам; в паре миров оно прошло (90–93) или нет (86–89). Нашего повтора работы, потери отчёта и
каналов нет: повторить может только сам Claude Code. Ключ ставит хук Claude Code, как это сделал
бы harness: снят (никто), ключ субагента, свой на каждого субагента (`task`), один на платёж
(`intent`). Правил у субагента нет; оркестратор может сам читать банк, но не платить.

## Главное

**Границу Claude Code не пересекает ни один дубль.** Opus ни разу не поручил оплату снова после
таймаута: второй субагент платил в 2 эпизодах из 168, оба раза после обычной ошибки банка, не
таймаута. Где списание прошло, но не видно, он отвечает «не знаю» (77 из 84).

**Все 7 дублей — повтор того же субагента.** После таймаута субагент Haiku сам повторяет оплату в
треть эпизодов (53 из 168). Дубль получается, только если у повтора другой ключ:

| Ключ | дубли, списание прошло (из 21) |
|---|---|
| никто (хук снимает ключ) | 6 |
| субагент сам | 1 (первая попытка без ключа, повтор — с ключом) |
| свой на каждого субагента | 0 |
| один на платёж | 0 |

Внутри одного субагента защищает любой постоянный ключ, даже «на субагента»: повтор — тот же
агент. В варианте А, где повтор устраивал стенд, ключ «на поручение» ломался при новом запуске.

**Цена осторожности.** Где списание не прошло и нужно было оплатить, оплата доведена до конца в 27
из 84 эпизодов, в остальных — «не знаю».

**Что это значит.** На настоящей границе Claude Code с Opus каскад «оркестратор поручает снова»
не возникает: он не повторяет работу вслепую. Дубли рождаются внутри исполнителя, и их закрывает
ключ на стороне harness. Это одна модель-оркестратор, один субагент и один тип сбоя; повторы, которые
устраивает сама система (M4, 48–59), здесь не проверялись.

**Цена и лимиты.** ~43 тыс. токенов промпта и 5,6 ответа оркестратора на эпизод, ~40 с. Оценка
Claude Code «сколько стоило бы по API» — $14,7 за 168 эпизодов; на подписке не списывается.
За прогон пятичасовое окно Pro выросло с 39% до 87%, недельное — с 5% до 11% (вместе с остальной
работой на аккаунте).
